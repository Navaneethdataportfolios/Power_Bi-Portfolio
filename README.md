## Sales Performance Report & Sales Trend Forecasting – Power BI

# Project Overview

This project focuses on analyzing sales performance and identifying sales trends using Microsoft Power BI. The interactive dashboard provides insights into business performance, revenue patterns, and future sales forecasts to support data-driven decision-making.

# Key Features

Sales Performance Analysis: Track key sales metrics and business performance.

Sales Trend Analysis: Identify sales patterns and trends over time.

Sales Forecasting: Visualize predicted future sales using forecasting.

Interactive Dashboard: Explore sales insights through interactive charts, graphs, and visualizations.

# Tools & Technologies

Microsoft Power BI

Power Query

DAX

Data Visualization

# Project Objective

To transform raw sales data into meaningful insights, understand historical sales performance, and forecast future sales trends to support better business decisions.
